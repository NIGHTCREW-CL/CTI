# Contribuciones

Las contribuciones deben aportar conocimiento verificable y favorecer el aprendizaje abierto. Este repositorio tiene una finalidad educativa y sin fines de lucro.

1. Proponer una mejora concreta e indicar el documento afectado.
2. Utilizar la metodología y la plantilla del área. Distinguir hechos, inferencias y resultados pendientes de verificación.
3. Citar fuentes originales y respetar autoría, licencias, embargos y condiciones de publicación.
4. Entregar únicamente contenido autorizado y anonimizado. Excluir credenciales, datos personales, información interna y muestras ejecutables de malware.
5. Explicar qué se cambió y cómo se comprobó en la solicitud de incorporación.

La colaboración exige respeto, precisión y responsabilidad. No se admiten instrucciones para actividades no autorizadas ni afirmaciones de impacto sin evidencia.

Los espacios públicos del repositorio se reservan para propuestas documentales; no son un canal para enviar información sensible o reportar incidentes.
